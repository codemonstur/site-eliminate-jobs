## Description

Develop and implement a set of techniques or analytics applications to transform raw data into meaningful information using data-oriented programming languages and visualization software. Apply data mining, data modeling, natural language processing, and machine learning to extract and analyze information from large structured and unstructured datasets. Visualize, interpret, and report data findings. May create dynamic data reports. It belongs to the Computer and Mathematical major group (code 15). They analyze, manipulate, or process large sets of data using statistical software. They create graphs, charts, or other visualizations to convey the results of data analysis using specialized software. They test, validate, and reformulate models to ensure accurate prediction of outcomes of interest. Most roles in this occupation sit at job zone 4 (substantial preparation).
