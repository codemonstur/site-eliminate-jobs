Computer and Mathematical

Major group 15 of the U.S. O*NET-SOC register, containing 38 of the 1,016 professions listed on this site.

Ways these jobs could be eliminated

  • AI code generation and agentic software engineering — Tools that write, refactor, and ship code from natural-language prompts. Examples: GitHub Copilot, Cursor.
  • Automated testing and bug triage — AI that generates tests, reproduces failures, and prioritizes bugs. Examples: Selenium, Cypress.
  • AutoML and automated model deployment — Platforms that train and deploy ML models with minimal human tuning. Examples: Google AutoML, H2O.ai.
  • LLM-assisted data analysis and querying — Natural-language interfaces over databases and datasets. Examples: ChatGPT Advanced Data Analysis, Claude.
  • AI-driven DevOps and incident response — Automation for deployment, monitoring, and on-call triage. Examples: Datadog, PagerDuty.
