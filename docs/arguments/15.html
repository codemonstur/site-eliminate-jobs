Computer and Mathematical

Major group 15 of the U.S. O*NET-SOC register, containing 38 of the 1,016 professions listed on this site.

Ways these jobs could be eliminated

AI code generation and agentic software engineering

AI tools can write, refactor, and ship code from natural-language descriptions, reducing the need for human programmers for routine development. Agentic systems can plan, implement, and test features autonomously.

This shifts software engineering toward higher-level design and oversight, with much of the implementation automated.

Examples

  • GitHub Copilot
  • Cursor
  • Wikipedia: Code generation

Automated testing and bug triage

AI can generate tests, reproduce failures, and prioritize bugs, reducing the manual work of QA engineers. Automated pipelines run continuously and surface issues without human monitoring.

This compresses the testing phase and reduces the need for large QA teams.

Examples

  • Selenium
  • Cypress
  • Wikipedia: Software testing

AutoML and automated model deployment

Platforms that train and deploy machine learning models with minimal human tuning reduce the need for data scientists and ML engineers. They automate feature engineering, model selection, and deployment.

This democratizes ML and shrinks the specialized workforce needed to build predictive systems.

Examples

  • Google AutoML
  • H2O.ai
  • Wikipedia: Automated machine learning

LLM-assisted data analysis and querying

Natural-language interfaces over databases let non-specialists query and analyze data without SQL or scripting. LLMs translate questions into queries and summarize results.

This reduces the need for data analysts and report writers for routine analysis.

Examples

  • ChatGPT Advanced Data Analysis
  • Claude
  • Wikipedia: Natural language processing

AI-driven DevOps and incident response

Automation handles deployment, monitoring, and on-call triage, reducing the need for DevOps and SRE staff. AI can detect anomalies, diagnose root causes, and even remediate automatically.

This compresses the operational work of keeping systems running.

Examples

  • Datadog
  • PagerDuty
  • Wikipedia: DevOps
