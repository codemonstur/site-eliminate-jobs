Penetration Testers

Description

Evaluate network system security by conducting simulated internal and external cyberattacks using adversary tools and techniques. Attempt to breach and exploit critical systems and gain access to sensitive information to assess system security. It belongs to the Computer and Mathematical major group (code 15). They document penetration test findings. They identify security system weaknesses, using penetration tests. They write audit reports to communicate technical and procedural findings and recommend solutions. Most roles in this occupation sit at job zone 4 (substantial preparation).
